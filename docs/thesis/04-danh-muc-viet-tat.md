| KLTN | Khoá luận tốt nghiệp | Graduation Thesis |

| NFR | Non-Functional Requirement | Yêu cầu phi chức năng |

| VND | Việt Nam Đồng | Đơn vị tiền tệ Việt Nam |

| WS / WebSocket | WebSocket Protocol | Giao thức kết nối hai chiều trên TCP |
